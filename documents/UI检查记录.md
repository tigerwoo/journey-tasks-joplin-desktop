# UI 一致性检查记录

检查范围：设置页、任务编辑／重复规则、日期和时间弹窗；320px 与 900px；英文、中文、德文设置页及深色设置页。浏览器检查使用编译后的真实组件和 Joplin 容器样式，不等同于在 Joplin 中手动验收。

| 问题 | 检查结果与修正 |
| --- | --- |
| 卡片标题不一致 | Journey Tasks 原为 14px／700／默认行高，另两个标题为 14px／600／24px。三个标题统一为 h2，共用 `.section-title`，14px／600／24px。 |
| 设置页操作文字不一致 | 原混用 13px、14px 及默认行高；按钮与按钮式链接统一 13px／500／20px，统一聚焦、悬停样式。 |
| 任务编辑操作文字不一致 | 原混用 11px、12px、14px；星期快捷按钮、模板操作、保存和下方操作统一 13px／500／20px。快捷按钮保留紧凑高度。 |
| 弹窗控件继承外层标签样式 | 日期／时间弹窗的文字原依赖所在表单的字号、行高；弹窗控件显式共用 13px／20px，标签和星期标题保留说明层级。 |
| 同级说明文字不一致 | 赞助说明原为 13px，其余设置说明为 12px；统一 12px／20px。 |
| 设置卡片间距不一致 | 设置表单原使用 14px 间距，其他卡片为 20px；统一相邻卡片间距为 20px。 |
| 表单高度和网格留白不一致 | 控件原依赖默认字体行高；统一输入和选择控件最小高度 36px、内容 13px／20px。标签统一 12px／18px、标签与控件间距 8px；移除网格内标签重复下边距，改由网格和区块控制间距。 |
| 抽屉滚动时标题栏裁切风险 | 原 sticky top 为 -16px，且窄屏内边距为 12px。标题栏统一 sticky top 为 0，关闭按钮固定 36px 点击区域；浏览器检查滚动后按钮完整可见。 |
| 窄屏外链标记孤立换行 | 原始笔记按钮的末尾箭头可能独占一行；标记与前面的词之间使用不换行空格，并检查两者实际位置处于同一行。 |
| 星期复选框与快捷操作零散换行 | 原所有复选框和快捷按钮混排；分成星期选项组与快捷操作组，组内保持间距，窄屏按组换行。 |

验证：`npm run check`；浏览器检查比较实际计算的字号、字重、行高、控件高度、卡片间距和滚动后的按钮位置，并生成截图逐项核对。浏览器命令：

```sh
JOURNEY_BROWSER=/path/to/chromium node --import tsx --test tests/browser/issue63-controls.test.ts
```
