## 4. 实现前必须验证的技术门槛

- 原生提醒 `todo_due` 与独立计划日期、稍后操作、原生界面修改的映射正确；两端取消和重排不会残留旧提醒。
- 系统数据笔记承载模板和操作记录的可恢复性、跨端同步与附件保活。公开 API 不支持真正隐藏普通笔记，设计需诚实说明可见性。
- 无事务/API无比较交换情况下采用最终收敛，不能声明跨设备立即只生成一次；证明合并后只保留一份活动后继且不丢正文。
- 农历年份和特殊规则、固定时区及夏令时策略可通过独立数据与性质测试验证。
- UI/日历批量读取和预览可满足测试方案的目标，目标不等于已测结果。
