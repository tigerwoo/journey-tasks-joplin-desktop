日视图每一条全天任务各有方形红节点与全天标签；定时任务圆形红节点，左时间、中节点、右任务及笔记本/重复列，沿定时节点绘竖线。周保持周日到周六七列，月保持七列并额外左侧周号，年保持四列三行十二个月。窄屏保留这些结构，仅对应日历或任务表局部横向滚动，不改逐日竖排、不自动变年历列数，不把整个面板横向撑出宿主。保留主纵向滚动和弹层可操作性。

PPT右侧解释文字不作为产品正文；月日期进入日（用户已纠正草稿笔误）、月周号进入周、年月份进入月/日期进入日。保留模板、原生菜单、同步与已验证宿主高度链。本轮必须分别验证宽窄屏结构及文字可读性，静态组件测试不能冒充实际宿主视觉验收。

## 1. 面板结构

桌面采用 Joplin 插件侧面板，首次沿用宿主右侧默认布局，之后尊重用户调整；Android 通过宿主插件面板标签页打开。不得调用不存在的公开 API 强制移动宿主面板。

```text
┌ 任务管理                         [设置] [更多] ┐
│ [今日] [未来七天] [月] [年]                    │
│ [上一个] 当前日期范围 [今天] [下一个]         │
│ □ 显示逾期（今日/七天）                      │
│                                             │
│ 逾期 / 日期分组 / 月格 / 年度概览            │
│ □ 任务标题  日期  优先级  重复/提醒标识       │
│   ⋯ 打开笔记 / 延期 / 跳过 / 编辑系列        │
│ ◌ 预计周期  日期  [预计，不生成笔记]         │
│                                             │
│ [新增任务]                                  │
└─────────────────────────────────────────────┘
```

新增是基础任务表单，不加入连续输入、多行批量创建或自然语言解析。移动端所有动作提供可见按钮或菜单；长按、滑动和快捷键只是可选的等效入口。

## 2. 四种视图

| 视图 | 数据和交互 |
| --- | --- |
| 今日 | 当天实际任务；逾期开关单独记忆；按全天/时间稳定排列 |
| 七天 | 今天至 T+6 按天分组，实际任务与预计周期分别标记；逾期开关不改变七天范围 |
| 月 | 完整周网格包含必要的相邻月日期；只查询网格覆盖范围；格内显示任务摘要和溢出计数，点击展开当日列表 |
| 年 | 十二个月日期概览，格点/数字表示当日任务，点击打开当天详情，不在小格堆叠全部标题 |

实际当前周期未完成或未跳过，不妨碍月/年视图计算未来预览。预计周期只读，不提供完成框，不创建原生笔记，不安排其提醒。按完成日期重复的未来预览依赖假设，应标“预计，实际日期取决于完成时间”；不能伪装成确定日程。

日历导航只改变浏览范围。视图启动模式与设备偏好按需求执行，月/年应用启动回今天所在范围，隐藏后重开保留当前位置。凌晨跨日和恢复前台重算，不依赖常驻高频轮询。

## 3. 任务操作

| 动作 | 行为 |
| --- | --- |
| 完成 | 按周期身份提交一次操作；成功落盘后更新状态，再推进后继投影；重复点击显示同一结果 |
| 跳过 | 显示“跳过本次并推进下次”，记为跳过而非完成；不编辑正文复选框 |
| 延期 | 选择晚于当前执行日期的日期/时刻，说明“仅延期当前任务，不改变重复规则”；展示提醒变化 |
| 编辑系列 | 展示原规则、修改后摘要和下次日期；保存影响当前及未来，不回写历史 |
| 撤销旧周期完成 | 在系列执行记录中操作；明确不会删除后继；旧周期再完成不重复推进 |
| 删除/结束重复 | 区分删除当前真实任务与结束系列；默认保留历史，列出实际影响，不提供模糊的一个删除按钮 |
| 打开笔记 | 只接受经过验证的实际 Joplin note ID；预计周期打开所属系列说明，而非不存在的笔记 |

原生笔记操作与插件发生冲突时，显示“数据已变化，请查看最新状态”；不以旧表单覆盖整个笔记或自动改写用户正文。

## 4. 新建与编辑表单

- 基础：标题、所属笔记本、全天日期/定时日期、四档优先级、提醒开关及单个提醒时刻。
- 时区：固定任务时区，默认设备当前值；显示 IANA 名称和必要的本地换算，不提供浮动模式。
- 重复：关闭/开启、历法、间隔、相应月日或星期参数、按计划/完成基准、结束条件。
- 系列模式：A 持续、B 周期归档，默认 A；切换说明“从下次推进起生效，已有内容保留”。
- B 模板：在插件内编辑标题和 Markdown 正文，保留有效资源引用；正文不会自动从本次执行记录回写。现有资源的选择/引用与附件添加能力通过宿主适配验证，不能先假设手机可访问任意文件路径。
- 表单提交前展示日期规则摘要及下次预计日期。模板保存与系列修改有明确独立操作边界，避免一处保存误覆盖所有未来任务。

非有效组合禁止提交：空标题、无基准日期却开启重复、非法月日、间隔小于一、结束早于开始、无效时区、超出可转换农历边界。不存在日期的月末回退按需求提示，不静默溢出。

## 5. 设置与 C11

设置：指定默认视图/恢复上次视图、固定目标视图、每视图逾期开关记忆及基础优先级排序。设备显示偏好不作为跨设备业务规则同步。

命令统一走应用服务，桌面注册 Joplin 命令与菜单，快捷键由宿主映射，Android 提供面板菜单等效入口。建议命令标识：`journey.showTasks`、`journey.newTask`、`journey.openSelectedTask`、`journey.completeSelected`、`journey.postponeSelected`、`journey.skipSelected`、`journey.editSeries`。

置顶为 C11 的任务显示偏好，作用于实际任务/系列，不能把无日期任务硬改成今日；同一日期组内置顶优先，再按优先级/时间稳定排序。移动端滑动动作为可选快捷入口，破坏性操作仍明确范围。

## 6. 异常与同步状态

- 区分初次加载、无任务、无日期、读取失败、离线可用和同步中，不将异常列表清空后显示“全部完成”。
- 系列并发规则冲突时停止新增后继，保留现有任务，提供查看两版规则和选择保留版本的恢复入口。
- 发现同一逻辑周期的多个笔记时，先标记待归并；有用户编辑内容的副本不得自动销毁。提醒抑制和恢复状态采用设计规范流程。
- 模板资源未下载时显示“附件尚未可用”，不删除资源链接或以空内容覆盖模板。
- 不认识的数据版本只读显示兼容提示，不降级重写。
- 显示系统数据载体的用途：它们不是待办，插件管理内容，但可能出现在原生笔记本和搜索中，不能承诺完全隐藏。

## 7. 消息与安全

面板不直接持有 Joplin API，只发送带版本和请求 ID 的受限动作；插件端验证动作、ID、当前版本和参数。UI 就绪后请求完整快照，不能只依赖可能丢失的推送；后续更新有快照版本，过期响应不得覆盖新视图。

用户标题使用文本节点；Markdown 预览必须清理危险 HTML/URL，不把笔记正文直接拼入执行脚本。面板消息无通用“执行任意命令/路径”的入口。日志只记录标识和错误码，默认不包含正文及附件内容。

## 8. 可访问性

键盘可到达视图、任务和菜单，焦点在列表更新后可恢复；每个图标具备名称。完成状态、优先级和预计周期不能只靠颜色表达。触摸热区以 44 CSS px 为目标，支持缩放与窄屏滚动，不用悬停承载唯一说明。真机字体、长中文标题和屏幕阅读器仍需验证。
