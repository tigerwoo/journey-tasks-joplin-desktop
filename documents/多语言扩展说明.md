# 多语言设置与语言文件扩展

## 使用设置

插件面板右上角齿轮 → 语言：跟随Joplin，或选择 26 个语言／地区选项之一。设置仅存当前设备，不随任务同步；面板立即切换，Joplin宿主菜单/命令名称下次启动更新。默认auto；旧偏好没有该字段时兼容为auto。

自动模式优先使用宿主的界面locale，读取失败使用运行环境locale。匹配注册语言的完整ID或语言家族，均不支持时回退中文。此选择不影响任务时区、公农历计算或用户内容。

## 语言文件目录

| 文件 | 职责 |
| --- | --- |
| [zh-CN.json](../src/i18n/locales/zh-CN.json) | 简体中文基准，定义完整语义键集合 |
| [en.json](../src/i18n/locales/en.json) | 英文翻译，键及占位符与中文一致 |

| [index.ts](../src/i18n/index.ts) | 解析语言、注册验证、逐键回退和命名插值；纯函数 |
| [react.tsx](../src/i18n/react.tsx) | React Provider/useTranslation；不改变组件业务状态 |

## 新增语言示例

以尚未支持的语言 `xx` 为例：

1. 复制en.json到`src/i18n/locales/xx.json`。
2. 只翻译值，不修改键；所有`{count}`、`{title}`等命名占位符保持不变。JSON必须有效，不加入注释，不嵌可执行HTML。
3. 在registry.ts添加导入和登记：

```ts
import example from './locales/xx.json';
// 在现有 registry 对象中增加：
xx: { id: 'xx', nativeName: 'Language name', dictionary: example },
```

4. 语言下拉、存储允许值和自动匹配从注册表生成，不需要逐个修改组件。
5. 将词条/占位符一致性测试覆盖到新注册项，再执行`npm run check`。当前测试遍历所有注册词典，检查词条、参数和模板标记。
6. 执行`npm run build`生成新JPL；安装到各设备后可选择新语言。

语言文件是源码配置，构建时离线打包。向publish目录直接放入JSON不会自动加载，修改已安装包内文件也不是支持的更新方式；请重新构建并安装。

## 新增词条与回退

使用语义键，如`view.today`、`actions.newTask`；中文英文都加入同名键。组件通过`t(key, params)`读取，避免拼接整句。例：带任务标题的动作使用`{title}`，标题本身仍是原始用户内容。

缺少目标语言词条时回退对应中文；完全未知键保留键名，缺失参数保留`{name}`以便发现漏配。参数只作为纯文本替换，既不递归翻译，也不执行HTML。

当前日期值保持ISO形式，月份名称、星期、农历说明、规则摘要等本地化显示。已知错误/诊断只在专用展示通道按错误码或已知文案映射，未知宿主技术详情保留原文；不扫描DOM翻译，不翻译标题、正文、笔记本名称或模板。既有数据笔记名称不因设备语言切换而重命名。

## 验证边界

自动化检查词典与占位符一致、locale解析与回退、旧偏好兼容、非法保存拒绝、重启及设备独立、英文静态渲染、用户中文标题保留/转义，以及切换语言不写任务或模板。实际Joplin即时选择与手机触控需要安装复测；不能把SSR视为点击测试。

## Issue 40 语言范围

按附件中完成度 ≥75% 的项目增加：加泰罗尼亚语、克罗地亚语、丹麦语、德语、英式英语、美式英语、西班牙语、芬兰语、法语、印度尼西亚语、意大利语、匈牙利语、荷兰语、波斯语、波兰语（75%）、巴西葡萄牙语、摩尔多瓦罗马尼亚语、罗马尼亚语、斯洛伐克语、瑞典语、土耳其语、俄语、繁体中文、日语。保留原有简体中文及通用英语 ID，兼容旧设备偏好。截图百分比仅用来确定语言范围，不是本插件的翻译完成度。

繁体中文由简体词典经 OpenCC 台湾词汇转换生成。其他新增词典以机器翻译为初稿，所有现有词条均提供对应值，尚未逐语言人工校译。运行时词典离线打包，不依赖翻译服务。英美英语分别登记；罗马尼亚与摩尔多瓦共享相同译文的独立文件。

自动模式支持下划线地区 ID；`zh-Hant`、台湾、香港、澳门选繁体，`zh-Hans` 优先选简体；罗马尼亚语默认匹配 `ro-RO`。波斯语设置面板文档方向为 RTL，切回其他语言恢复 LTR。

### 术语校对（评论截图）

繁体词典不能只依赖自动繁简转换：单字“周”与整词“本周”的转换结果可能不同。已将繁体词典中时间含义的“周”统一校为“週”，覆盖视图选择、本週／上一週／下一週、周数栏、无障碍说明、每週重复及规则摘要；简体继续使用“周”。回归测试同时渲染视图选择器与日期导航，检查截图中的两个位置，以及月历周数和重复规则术语。其他语言也校对了周数栏残留的英语缩写、罗马尼亚语重音和日语“今年”标签。词条完整性测试不代表所有语言已完成母语校译。
